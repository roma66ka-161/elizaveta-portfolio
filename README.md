# Elizaveta Pidkova portfolio

GitHub Pages mirror of the existing portfolio. The Beget deployment remains independent.

The visual design and content are preserved. GitHub Pages does not run PHP, so this copy generates the model card PDF in the browser and serves existing WebP previews directly. The model age still updates automatically.

Publish the `main` branch from `/ (root)` in Settings → Pages.
Original canonical URLs are retained for the existing primary site on Beget.

Photos, videos and other creative material retain their respective owners' rights. No new license is granted by this mirror.
